# Party Mode — Pitch Deck

A concept pitch for **JioSaavn**: a premium "Party Mode" that auto-plays the peak of every
song and crossfades between them — backed by the working "Groovy" prototype in this repo.

## Files
- **`party-mode-deck.html`** — the presentation. Self-contained, no dependencies.
- **`party-mode-deck.md`** — the same narrative as plain copy, plus short tweet/DM versions.

## How to present
1. Open `party-mode-deck.html` in any browser (double-click it).
2. Navigate with **← / →** (or Space), **Home/End** to jump, or the on-screen ‹ › buttons.

## Export to PDF (for emailing)
1. Open the deck in Chrome → **Print** (Ctrl/Cmd-P).
2. Destination: **Save as PDF**. Each slide prints as its own page.
3. Tip: enable "Background graphics" in print options to keep the colors.

## Before you send
- All market figures (weddings, market size, streaming users, conversion lift) are
  **illustrative estimates**. Replace them with sourced numbers — they're flagged in the
  deck and in `party-mode-deck.md`.
